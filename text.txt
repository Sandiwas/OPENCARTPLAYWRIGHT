// GitHub Actions + Headless Mode Notes
// GitHub Actions generally runs Playwright tests in headless mode.
// In headless mode, no browser window is opened.
// Since there is no browser window, --start-maximized has no practical effect.
// Therefore, launchOptions: { args: ["--start-maximized"] } is not recommended for CI.
// To control the browser size in GitHub Actions, use the viewport property.
// Example:
// use: {
//   headless: true,
//   viewport: {
//     width: 1280,
//     height: 720,
//   },
// }
// Local vs GitHub Actions
// Local Machine	GitHub Actions
// headless: false	headless: true
// --start-maximized can be used	--start-maximized is not needed
// Browser window opens	No browser window opens
// Maximize works	Use viewport to set browser size
// One-line Interview Answer

// In GitHub Actions, Playwright tests run in headless mode, so --start-maximized is unnecessary. We use the viewport property to control the browser resolution instead.
